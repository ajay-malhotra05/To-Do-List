# 📝 To-Do List App

A simple and responsive **To-Do List** application built using **HTML, CSS, and Vanilla JavaScript**.

This is my **first JavaScript project**, created to practice the fundamentals of JavaScript by building a real-world application without using any frameworks or a backend.

---

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- ❌ Delete tasks
- 📊 Live completion percentage
- 📈 Dynamic progress bar
- 📌 Remaining task counter
- 🎭 Homelander's emotions change based on your completion percentage

---

## 🎭 Homelander Mood System

Complete your tasks to change Homelander's mood!

| Completion | Mood |
|------------|------|
| **0%** | 😐 Neutral |
| **25%** | 🙂 Slightly Happy |
| **50%** | 😎 Confident |
| **75%** | 😁 Proud |
| **100%** | 🏆 Truly Happy |

The more tasks you complete, the happier Homelander becomes.
